What is being demonstrated is the analysis and the data model behind it, not a view of anyone’s performance.

About this build. This is a portfolio demonstration, not a Magna asset. It runs on a synthetic dataset of 9,400 records-retrieval requests generated in the browser from a fixed seed — no client, custodian, or patient data of any kind. Every number on the page, including the percentiles and the source-health counts, is computed live from that dataset, so the filters genuinely re-cut the analysis rather than swapping canned images.

What it is standing in for. In production this would be a Sigma workbook over Snowflake: a dbt-modelled request fact at one row per retrieval request, event-level stage timestamps, conformed client and custodian dimensions, and certified metric definitions carried in the semantic model rather than re-derived in each workbook. The definitions drawer shows the SQL behind each headline number and the exclusions applied to it.
